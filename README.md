## Local Setup
1. Run `./localsetup.sh` to setup a local virtual environment
2. In VS Code, hit `Cmd + Shift + P` and search for "Python: Select Interpreter" to select `<ProjectFolder>/VERA/venv/bin/python`
3. In the Jupyter notebook, select the same path for the kernel
